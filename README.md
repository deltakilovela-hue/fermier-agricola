# Fermier — Laboratorio y Asesoría Agrícola

Repositorio con los dos entregables HTML autocontenidos (imágenes y video embebidos como base64, sin dependencias externas salvo Google Fonts):

- [`web/index.html`](web/index.html) — sitio web público de Fermier (Servicios, Microsin, Nosotros, Contacto).
- [`brand/identidad_de_marca.html`](brand/identidad_de_marca.html) — propuesta de identidad de marca, para revisión interna/cliente.

Ambos archivos se pueden abrir directamente en el navegador o servir con cualquier hosting estático (ej. GitHub Pages).
